# AWS Well-Architected Framework: Operational Excellence Lab Guide

## Introduction

Welcome to the hands-on lab for **AWS Well-Architected Framework: Operational Excellence**. In this lab, you will learn how to build an automated monitoring and alerting system to ensure your application operates efficiently and reliably.

### Lab Objectives

- Understand and apply the principles of Operational Excellence  
- Build an automated monitoring system using CloudWatch  
- Implement alerting and automated response mechanisms  
- Optimize operational processes using Infrastructure as Code  

### Prerequisites

- Basic knowledge of the AWS Console  
- Understanding of EC2, CloudWatch, SNS, and Lambda  
- Experience with CloudFormation (for the advanced section)
